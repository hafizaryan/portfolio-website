# Anti-Slop Audit 001 — Projects Section (Mode 2: AFTER)

**Date:** 2026-11-18  
**Scope:** `src/components/projects.tsx` and `src/app/globals.css` (lines 1-60, 200-440)  
**Design System:** Cream (`#F3EEE3`) dominant · Ink Black (`#111111`) · Burnt Orange (`#D9541E`) accent  
**Mode:** `antislop` Mode 2 (AFTER) — read-only audit; no source files modified.

## Findings

1. **[HIGH] `R-26` (Interactive Elements — Hard Gate)**
   - **Reason:** In `src/components/projects.tsx` (lines 31-37, 231-258), the `lab` project defines `repo: "#"` and `demo: "#"`, rendering two dead `<a>` buttons that open the current page in a new tab instead of a real destination.
   - **Recommended Fix:** Remove `repo: "#"` and `demo: "#"` from `lab` (matching `aurora` and `sitaris`) or replace them with real URLs; if temporarily unavailable, remove the links and show a non-interactive `"Coming soon"` label with a `// TODO` comment.

2. **[HIGH] `R-25` (Color Contrast — Hard Gate)**
   - **Reason:** In `src/app/globals.css` (lines 343-374), `.project-card--lab` places `#ffffff` and `rgba(255, 255, 255, 0.85)` text on `#3b82f6` (~3.68:1 and ~3.01:1), and `11px` tag pills on `rgba(0, 0, 0, 0.14)` over `#3b82f6` (~3.85:1), failing WCAG AA 4.5:1 for normal text.
   - **Recommended Fix:** Eliminate `#3b82f6` and the other ad-hoc card backgrounds; use the Cream (`#F3EEE3`) / Surface (`#EAE3D5`) / Surface Raised (`#F8F4EC`) surfaces with Ink Black (`#111111`) text (>14:1 contrast) or Ink Black (`#111111`) surfaces with Cream (`#F3EEE3`) text (>15:1 contrast), reserving Burnt Orange (`#D9541E`) for accents, borders, and active highlights.

3. **[HIGH] `R-03` (Mobile Responsiveness — Hard Gate)**
   - **Reason:** In `src/components/projects.tsx` (lines 236, 250), Repo/Demo `<a>` buttons use `px-3 py-1.5 text-sm` (~34px height, below the 44px minimum tap target), and in `src/app/globals.css` (lines 205-240), `.project-header` (`top: 46px`) plus `.project-stack` (`--stack-top-base: 180px`) and auto-height cards (`min-height: 340px`) crowd short mobile viewports and can clip sticky cards.
   - **Recommended Fix:** Ensure Repo/Demo buttons meet `min-h-[44px]` (`inline-flex items-center`) on mobile, tighten mobile card padding (`1.25rem`), and adjust `--stack-top-base` (or disable sticky stacking on `<768px`) so no card clips off-screen.

4. **[HIGH] `R-40` (Performance Mechanisms — Hard Gate)**
   - **Reason:** In `src/components/projects.tsx` (lines 282-286), project thumbnail `<img>` elements omit explicit `width` and `height` HTML attributes.
   - **Recommended Fix:** Add explicit intrinsic `width` and `height` attributes (e.g., `width={1280} height={720}`) alongside `aspect-ratio: 16 / 9` on each project `<img>` to prevent layout shift before CSS resolves.

5. **[HIGH] `R-39` (Accessible Semantics & Interaction Affordances — Hard Gate)**
   - **Reason:** In `src/components/projects.tsx` (lines 310-323), the GitHub card's large icon sits outside the `<a>` tag (non-clickable visual affordance), and `"View More Project on Github"` is hardcoded in English instead of using `useTranslations("projects")`, while `.project-card--sitaris` / `.project-card--github` lack `--accent` (`#D9541E`) hover/active affordances.
   - **Recommended Fix:** Wrap both the GitHub icon and localized label (`t("viewMoreGithub")`) inside a single accessible `<a>` with `min-h-[44px]`, and apply consistent `--accent` (`#D9541E`) / `--ink` (`#111111`) hover and active states across all project links.

6. **[MEDIUM] `R-01` (Color & Gradients — Purpose-Gate)**
   - **Reason:** In `src/app/globals.css` (lines 331-383, 258-263), the 4 saturated card colors (`#7f1d1d`, `#3b5bdb`, `#3b82f6`, `#4338ca`) have no hierarchy rationale in the Cream/Ink/Burnt Orange system, and `.project-card::after` uses raw `rgba(0, 0, 0, 0.45)` instead of Ink Black (`#111111`).
   - **Recommended Fix:** Replace the 4 per-card hex overrides with Cream/Surface/Ink Black card treatments accented by Burnt Orange (`#D9541E`), and update `.project-card::after` to `rgba(17, 17, 17, 0.35)` so stacking depth shading matches `#111111`.

7. **[MEDIUM] `R-14` (Feature Cards — Purpose-Gate)**
   - **Reason:** In `src/components/projects.tsx` (lines 211-296) and `src/app/globals.css` (lines 231-295, 412-432), all 5 project cards are structurally identical copy-paste blocks (`340px` height, identical 2-column grid, identical padding, identical tag/media layout) with no hierarchy differentiation.
   - **Recommended Fix:** Introduce intentional hierarchy variation aligned with the 3-color palette—for example, style the lead project (`aurora`) as an Ink Black (`#111111`) inverted card with Cream (`#F3EEE3`) text and a Burnt Orange (`#D9541E`) index/badge, while styling subsequent cards on Surface Raised (`#F8F4EC`) / Surface (`#EAE3D5`) with `--rule` (`#D8CFC0`) borders and Burnt Orange (`#D9541E`) `01`–`05` index markers.

8. **[MEDIUM] `R-19` (Animations — Purpose-Gate)**
   - **Reason:** In `src/components/projects.tsx` (lines 58-196), the sticky-stack scroll animation has no documented UX purpose / MOTION dial rationale, and `headerRef.current.style.transform` (lines 95-101) executes before the `if (motionQuery.matches)` reduced-motion guard on line 103.
   - **Recommended Fix:** Document the stack animation's UX purpose (sequential depth cue while scrolling) and guard/reset `headerRef` cleanly under `prefers-reduced-motion: reduce`.

9. **[LOW] `R-29` (Color Palette — Quality Locks)**
   - **Reason:** In `src/app/globals.css` (lines 331-353), `#7f1d1d`, `#3b5bdb`, `#3b82f6`, and `#4338ca` introduce 4 unrelated saturated colors on top of Cream (`#F3EEE3`), Ink Black (`#111111`), and Burnt Orange (`#D9541E`), creating a 6+ color clash on the page and leaving `sitaris`/`github` on `#EAE3D5`.
   - **Recommended Fix:** Unify all 5 project cards and the GitHub card under the 3-color system (`#F3EEE3` / `#EAE3D5` / `#F8F4EC` Cream surfaces, `#111111` Ink Black, `#D9541E` Burnt Orange accent) with zero extra hue families.

10. **[LOW] `R-31` (Every Decision Must Have a Reason — Quality Locks)**
    - **Reason:** Neither `src/components/projects.tsx` nor `src/app/globals.css` records the one-line rationale for card surface choices, sticky-stacking geometry, or button/tag hierarchy.
    - **Recommended Fix:** Add concise one-line comments documenting the purpose of each layout, color-token, and motion choice alongside the Cream / Ink Black / Burnt Orange refactor.
